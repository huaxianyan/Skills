# README 骨架模板

文件名固定 `README.md`，全小写。

</div>

> <声明，如仅个人学习使用、非官方背书、账号风险提示>

<有可视界面才保留。整组图若需要语境，先写一句概括。>

## 使用的三条提醒

- 节按此顺序出现，可省略不乱序。删节的标准：删掉后读者会不会卡住。
- Markdown 骨架里嵌了 ```bash 代码块。本文件外层围栏必须保持四个反引号：开头是 ````markdown，许可证节后的闭合是 4 个反引号，内部 ```bash 才不会提前闭合外层。若外层退化成三反引号，CommonMark 会把骨架后半段渲染成正文。
- 复制后先删所有「（可选）」标记与说明性尖括号注释，再填内容。填不出来的节直接整节删掉，不保留空节。
